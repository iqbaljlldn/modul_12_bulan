# 0.1 Tentang Bulan Pertama: Fondasi Pra-Coding

Selamat datang di program 12 Bulan Kurikulum Project-Based Learning!

Mungkin kamu bertanya-tanya: **"Katanya kita belajar menjadi Software Engineer, kenapa di bulan pertama ini kita fokus berpikir dan merancang, bukan langsung ngoding seharian?"**

Pertanyaan ini sangat wajar. Mari kita bedah alasannya.

---

## 1. Masalah Terbesar Programmer Pemula

Banyak orang belajar pemrograman dengan cara melompat langsung ke sintaks bahasa:
```text
Belajar if-else → loop → function → langsung buka VS Code mau bikin aplikasi
  → Bengong di depan layar kosong: "Mau mulai dari mana ya?"
  → Copy-paste dari internet / prompt AI tanpa paham alur
  → Muncul bug → bingung cara memperbaikinya karena logikanya sendiri belum matang
```

Di industri software profesional, **menulis kode hanyalah 20-30% dari pekerjaan seorang engineer**. 70-80% sisanya adalah:
1. **Memahami masalah pengguna** (Siapa yang pakai aplikasi ini? Apa masalah mereka?).
2. **Merancang logika penyelesaian** (Bagaimana urutan langkahnya? Apa kondisi jika gagal?).
3. **Memodelkan data** (Informasi apa saja yang perlu disimpan? Bagaimana hubungannya?).
4. **Berkomunikasi dan berkolaborasi** (Bagaimana menjelaskan ide ke tim dan pemangku kepentingan?).

Bulan 1 ini dirancang khusus untuk membangun fondasi cara berpikir dan merancang tersebut. Kamu tidak perlu khawatir kehilangan kemampuan teknis: **kita tetap menjaga memori otot ngoding lewat latihan kode kecil terarah setiap minggu**, sementara sebagian besar energimu diarahkan untuk menguasai logika sistem sebelum coding React dan TypeScript dimulai intensif di Bulan 2.

## 2. Peta Perjalanan Bulan 1

Bulan 1 berlangsung selama 4 minggu dengan ritme 6 sesi per minggu (Senin–Jumat materi & workshop, Sabtu sprint review / evaluasi):

```text
Minggu 1: AI Literacy & Etika
└─ Belajar memakai AI sebagai mitra diskusi cerdas, bukan mesin jalan pintas malas.
   Artefak: Piagam Etika AI Tribe & Cheat Sheet Prompt Engineering.

Minggu 2: Computational Thinking & Algoritma
└─ Membedah masalah menjadi langkah runtut, flowchart visual, skema data (ERD), serta jembatan logika kode JS kecil.
   Artefak: Peta Dekomposisi, Pseudocode, Flowchart Sistem, Draft ERD, Latihan Kode JS.

Minggu 3: Desain Aplikasi & Bisnis UMKM
└─ Berpikir dari kacamata user nyata (UX) berbasis wawancara UMKM sekitar dan wireframe katalog.
   Artefak: Review UX, Wireframe 3 Halaman, Value Proposition Canvas, Hasil Wawancara UMKM, Latihan HTML/CSS.

Minggu 4: Pitching, Alur Terpadu, & Showcase
└─ Merangkai semua artefak, memvalidasi alur pemesanan WA, mengelola repo Git, dan presentasi di Showcase Day.
   Artefak: User Flow Tervalidasi, Slide Pitch Deck 7 Halaman, Repositori Git Tim, Sesi Pitch Day.
```

## 3. Filosofi: Belajar Berbasis Produk (PBL)

Di sini kita tidak belajar teori abstrak di awang-awang. Sejak Minggu 1 sampai Bulan 12, semua studi kasus berpusat pada satu produk nyata: **Platform Katalog & Manajemen UMKM (dengan alur pemesanan langsung ke WhatsApp penjual)**.

- Kamu akan membedah proses jualan pedagang warung, toko kue, atau pengrajin lokal di sekitarmu.
- Kamu akan merancang bagaimana mereka memasukkan produk, bagaimana pembeli mencari barang, dan bagaimana pesanan dikirimkan via WhatsApp.
- Saat masuk Bulan 2 nanti dan mulai membuat komponen React, kamu sudah tahu persis **kenapa komponen itu dibuat, untuk siapa, dan alur kerjanya seperti apa**.

---

## 4. Peran AI dalam Belajar

Kamu **diperbolehkan bahkan didorong** menggunakan AI (ChatGPT, Claude, Gemini, dll). Namun ada aturan main penting:
- **AI adalah asisten diskusi (co-pilot)**: Gunakan untuk brainstorming, mencari analogi, atau menguji alur berpikirmu.
- **Kamu yang bertanggung jawab penuh atas hasilnya**: Jika AI memberikan jawaban yang salah atau halusinasi dan kamu menelannya mentah-mentah, kamu yang dinilai tidak memahami materi.
- **Prinsip Mandiri**: Jika kamu tidak bisa menjelaskan alasan di balik suatu keputusan desain atau alur flowchart di depan mentormu tanpa bantuan AI, berarti kamu belum memahaminya.

---

## 5. Yang Harus Kamu Siapkan untuk Bulan Ini

1. **Buku catatan / kertas HVS & spidol:** Di Minggu 2 dan 3, membuat sketsa di kertas jauh lebih cepat merangsang ide sebelum dipindahkan ke format digital.
2. **Akun AI:** Akses ke setidaknya satu LLM (misal: ChatGPT, Claude, atau Gemini).
3. **Akun Git & GitHub:** Untuk menyimpan dan menyerahkan artefak serta latihan tim.
4. **Mindset terbuka dan siap berkolaborasi:** Kesuksesanmu bulan ini sangat bergantung pada seberapa aktif kamu berdiskusi dalam squad.
