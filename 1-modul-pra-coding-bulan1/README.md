# Modul Belajar — Bulan 1: Fondasi Pra-Coding

Modul ini bahan ajar untuk **12 Bulan Kurikulum Project-Based Learning** (Platform UMKM), khusus **Bulan 1 — Fondasi Pra-Coding**. Bulan ini sepenuhnya membangun bekal berpikir sebelum menulis satu baris kode pun: AI Literacy, Computational Thinking & Algoritma, Desain Aplikasi & Bisnis, dan Pitching.

Coding (TypeScript + React) dimulai di **Bulan 2**.

## Cara pakai

- **Mentor:** baca `PANDUAN-MENTOR.md` di tiap folder sebelum mengajar minggu itu. Isinya urutan sesi, alokasi waktu, jebakan umum, dan checkpoint mingguan.
- **Peserta:** baca bab sesuai urutan nomor. Tiap sesi punya materi inti dan praktik/workshop yang menghasilkan **artefak nyata**.
- Semua output Bulan 1 bersifat project-based — tiap minggu ada artefak konkret.

## Ritme mingguan

| Hari | Isi |
|---|---|
| **Senin–Jumat** | Sesi materi + workshop (5 sesi) |
| **Sabtu** | Sprint review / evaluasi mingguan (1 sesi) |

Total: **6 sesi/minggu**, **24 sesi/bulan**.

## Squad

6 squad rolling @3 orang, ganti tiap 1-2 minggu. Meskipun belum ngoding, peserta sudah bekerja dalam tim kecil sejak hari pertama — membiasakan kolaborasi, pembagian peran, dan komunikasi.

## Artefak yang dihasilkan peserta

| Minggu | Artefak |
|---|---|
| 1 | Piagam Etika AI Tribe, Cheat Sheet Prompt Engineering, presentasi mini AI |
| 2 | Peta dekomposisi, algoritma/pseudocode, flowchart (min. 2/squad), ERD draft |
| 3 | UX Review, wireframe 3 halaman, Value Proposition Canvas, persona UMKM |
| 4 | User flow tervalidasi, pitch deck, repo Git berisi semua artefak |

## Checkpoint keluar Bulan 1

Tiap peserta bisa:
1. Memecah masalah menjadi langkah runtut menggunakan 4 pilar computational thinking
2. Menggambar flowchart alur fitur sederhana
3. Menggambar ERD dasar (entitas, atribut, relasi)
4. Menggambar wireframe halaman sederhana
5. Menjelaskan value proposition Platform UMKM dari sudut pandang UMKM dan buyer
6. Memakai AI sebagai asisten dengan prompt yang jelas dan tetap memvalidasi hasilnya
7. Melakukan pitching 5-7 menit dengan struktur Problem → Solusi → Demo → Hasil
8. Memakai Git dasar untuk menyimpan dan membagikan artefak
