# 04f. Showcase Pitch Day: Panggung Pembuktian Bulan 1

## 1. Hari Ini Adalah Panggung Pembuktianmu!

Selamat datang di **Showcase Pitch Day Bulan 1**!

Empat minggu lalu, kamu memulai fase pra-coding ini mungkin dengan rasa cemas: belum pernah merancang sistem software, bingung membedakan *Entitas vs Atribut*, ragu berbicara di depan umum, atau belum tahu cara memanfaatkan AI secara terarah.

Hari ini, di hadapan seluruh rekan tribe, para mentor, dan tamu undangan, setiap squad akan berdiri di atas panggung membuktikan bahwa kalian memiliki:
- **Daya nalar logika komputasional yang runtut dan presisi.**
- **Empati mendalam terhadap masalah nyata pelaku UMKM di sekitar.**
- **Kemampuan komunikasi persuasif berbasis bukti artefak digital nyata.**

> [!NOTE]
> **Sabtu Bebas PR:** Tidak ada tugas mandiri individual setelah acara Showcase hari ini selesai. Seluruh presentasi dan refleksi akbar Bulan 1 dituntaskan langsung di dalam kelas agar kamu bisa beristirahat di akhir pekan sebelum memulai coding React di Bulan 2 hari Senin!

## 3. Aturan Main di Atas Panggung

1. **Disiplin Waktu 7 Menit:** Pada menit ke-6, mentor mengangkat penanda kuning (1 menit tersisa). Pada menit ke-7 pas, penanda merah diangkat dan presentasi dihentikan.
2. **Keterlibatan Penuh Anggota:** Seluruh anggota squad wajib berbicara di panggung dan menjawab pertanyaan panelis secara bergantian sesuai peran.
3. **Etika Audiens:** Peserta yang tidak sedang tampil wajib menyimak seksama, menutup laptop, dan mengisi catatan apresiasi *peer-feedback*.

## 4. Evaluasi 8 Checkpoint Kapabilitas Pra-Coding

Di akhir Showcase, mentor mengevaluasi kesiapan setiap murid menggunakan **Checklist 8 Kapabilitas Inti** dengan 3 status: **Siap**, **Hampir Siap**, atau **Perlu Pendampingan**. Tidak ada vonis nilai angka atau skor yang menghukum.

| # | Checkpoint Kapabilitas | Bukti Pengujian Nyata | Status Kesiapan | Catatan Masukan Mentor |
|---|---|---|---|---|
| **1** | **Computational Thinking** | Mampu memecah masalah bisnis runtut tanpa ambigu (Dekomposisi, Pola, Abstraksi, Algoritma/Pseudocode baku). | [ ] Siap<br>[ ] Hampir Siap<br>[ ] Perlu Pendampingan | |
| **2** | **Alur Flowchart Baku** | Menggambar alur sistem dengan simbol standar baku, percabangan jelas (*Ya/Tidak*), dan alur pemesanan WhatsApp lengkap. | [ ] Siap<br>[ ] Hampir Siap<br>[ ] Perlu Pendampingan | |
| **3** | **Pemodelan Data ERD Dasar** | Membedakan entitas, atribut unik (*PK*), relasi 1:N, dan entitas penghubung `ItemPesanan` untuk relasi N:N. | [ ] Siap<br>[ ] Hampir Siap<br>[ ] Perlu Pendampingan | |
| **4** | **Wireframe Mobile-First** | Merancang tata letak antarmuka di Figma (Katalog, Detail, Dashboard) yang ramah bagi pengguna awam UMKM. | [ ] Siap<br>[ ] Hampir Siap<br>[ ] Perlu Pendampingan | |
| **5** | **Value Proposition & Riset Pengguna** | Menjelaskan nilai solusi berbasis data wawancara UMKM nyata (`catatan-wawancara-squad.md`) dan persona yang membumi. | [ ] Siap<br>[ ] Hampir Siap<br>[ ] Perlu Pendampingan | |
| **6** | **AI Literacy & Etika** | Memakai AI sebagai sparring partner terstruktur (formula R-C-I-C-O), memvalidasi fakta, dan patuh Piagam Etika Tribe. | [ ] Siap<br>[ ] Hampir Siap<br>[ ] Perlu Pendampingan | |
| **7** | **Komunikasi & Pitching 7 Menit** | Menyampaikan narasi produk percaya diri dengan struktur Problem → Solusi → Bukti/Demo → Dampak → Roadmap. | [ ] Siap<br>[ ] Hampir Siap<br>[ ] Perlu Pendampingan | |
| **8** | **Kolaborasi Git & GitHub** | Mengelola seluruh artefak dan latihan kode ke repositori GitHub tim melalui alur branch dan Pull Request yang rapi. | [ ] Siap<br>[ ] Hampir Siap<br>[ ] Perlu Pendampingan | |

> *Catatan Pendampingan:* Murid yang mendapatkan status **Perlu Pendampingan** pada salah satu checkpoint akan mengikuti sesi klinik santai bersama mentor pada hari Senin pagi sebelum coding React dimulai, agar semua melangkah ke Bulan 2 bersama-sama.

---

## 5. Penghargaan Apresiasi Squad (*Tribe Awards*)

Di akhir acara, mentor mengumumkan penghargaan apresiasi tim:
- 🏆 **The Best Overall Pitch:** Squad dengan narasi paling memukau dan penguasaan panggung paling percaya diri.
- 📐 **The Master Architect:** Squad dengan kualitas flowchart, user flow, dan ERD paling rapi serta tahan uji skenario batas (*edge cases*).
- 💡 **The Deepest User Empathy:** Squad dengan riset wawancara UMKM paling mendalam dan solusi UX paling menyentuh kebutuhan pedagang kecil.

---

## 6. Refleksi Akbar di Kelas (15 Menit Sebelum Penutup)

Sebelum sesi Showcase ditutup, luangkan waktu 15 menit di ruangan untuk menuliskan **3 poin refleksi singkat** di buku catatan atau forum kelas:
1. **Perubahan Pola Pikir:** Apa perbedaan terbesar cara berpikirmu di awal Bulan 1 vs sekarang setelah 4 minggu merancang sistem?
2. **Checkpoint Paling Membanggakan vs Perlu Diasah:** Dari 8 checkpoint di atas, mana yang paling kamu kuasai dan mana yang ingin kamu perkuat di Bulan 2?
3. **Kesiapan Bulan 2:** Satu target pribadi yang ingin kamu capai di minggu pertama belajar React & TypeScript hari Senin nanti.

*(3–4 perwakilan peserta boleh membacakan refleksinya singkat di depan kelas.)*

---

## 7. Output Sesi (Diselesaikan di Kelas)

1. Lembar Checklist 8 Kapabilitas untuk seluruh 12 murid.
2. Repositori GitHub final masing-masing squad yang telah diverifikasi oleh mentor.
3. Refleksi Akbar Bulan 1 yang dituntaskan langsung di dalam kelas *(tidak ada PR tambahan setelah kelas berakhir)*.
